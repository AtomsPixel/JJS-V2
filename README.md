# JJS: Cursed Energy (Fabric 1.20.1)

Build: `./gradlew build` (add the Gradle wrapper from the Fabric example mod) -> jar in build/libs.
Needs Fabric API 0.92.2+1.20.1, Java 17.

On first join the character select screen opens. Press J any time to reopen it.

Keys: Z X C V = the four techniques (V is the Domain / Ultimate), R = Reverse Cursed Technique,
G = toggle reinforcement, J = character select. Rebind in Controls > JJS: Cursed Energy.
Stand still and sneak to recharge cursed energy faster.
